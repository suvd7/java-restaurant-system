# Java Restaurant Recipe Book System
A simple restaurant management system that allows tracking recipes, available stock, and missing ingredients via a shopping list.

## Features
- Define and store recipes with ingredients
- Maintain stock of ingredients
- Automatically generate a shopping list when stock is insufficient
  
## Technologies Used
- Java

## How to Use
1. Add ingredients to stock.
2. Create and store recipes.
3. Try to prepare recipes:
   - If ingredients are available: recipe is prepared.
   - If not: missing ingredients go to the shopping list.
